# SimFlow_PluginTest

Unreal Engine host project used to develop and exercise the **SimFlow**
task/flow framework plugin. The rest of the project is an Unreal template
host that provides maps and characters to test the plugin against.

## Engine Version
- Unreal Engine 5.6

## Requirements
- Visual Studio 2022 (with "Game development with C++" workload)
- Windows 10/11 64-bit

## Setup
1. Clone repository
2. Open `SimFlow_PluginTest.uproject`
3. Generate Visual Studio project files (right-click the `.uproject` →
   *Generate Visual Studio project files*)
4. Build project
5. Launch project

> `Binaries/`, `Intermediate/`, `Saved/` and `DerivedDataCache/` are not
> tracked in git. They are regenerated by steps 3–4 above.

## Required Plugins
Bundled in `Plugins/`:
- **SimFlow** — task/flow framework (the plugin under development)
- **InventoryBubble** — inventory system
- **VRExpansionPlugin** / **OpenXRExpansionPlugin** — VR locomotion and interaction
- **AdvancedSessions** — session/networking blueprint nodes

Engine plugins enabled in the `.uproject`:
- ModelingToolsEditorMode, StateTree, GameplayStateTree, XRBase,
  OpenXR, OpenXRHandTracking

## Working Notes
- **Close the Unreal Editor before pulling or switching branches.**
- Unreal assets (`.uasset`, `.umap`) are binary and cannot be merged —
  tell the team before editing a shared map or blueprint.
- Save and compile before committing.
